Replicate

Every NEEC result can be reproduced by anyone, in three ways: re-run the arithmetic, check one score against its evidence, or have an AI system score a system for itself.

Re-run every computation

The repository holds the script behind every published figure, and a harness that runs them all and compares the output, byte for byte, with the captured run. It needs Python 3.12 (standard library only) and, for three checks, Node.js.

git clone {{repo}}.git
cd NormativeEvaluation
python3 run_all_checks.py > out.txt
cmp out.txt run_all_checks_output.txt

If cmp prints nothing, your run matches. Every working session is merged only after the same check passes on the merged repository.

Check one score

  1. Open the criterion's page, or criteria.json, and read its Pass Threshold clause by clause, with the anchors for 1.0, 0.5 and 0.0.
  2. Open the system's page and its scoring documents, which give the evidence and the reasoning for each score.
  3. Decide, clause by clause, whether the named evidence shows the clause met. A 1.0 needs every clause shown; silence is not clearance.
  4. If you reach a different score, note by how much and why, and report it.

When your result differs

A difference is the most useful thing a check can find. Before reporting one, sort it into one of four kinds, because each is handled differently:

Evidence
A figure is wrong or out of date, or a source does not say what is claimed. This is a correction, made whether or not anyone disputes the judgment.
Interpretation
The same evidence, read against the same clause, gives you a different score. Quote the passage you disagree with.
Scope
You scored a different configuration or date, or counted in a mechanism the entry leaves out (protocol section 3).
Protocol
The protocol is silent or ambiguous at this point. These become revisions of the protocol.

Then report the check, whether it agrees or not: paste the AI's whole answer with its JSON block, and name the model, the interface and the date. Confirmations are logged as carefully as disagreements, because independent confirmation is evidence too. The maintainers reproduce each report and record what they decide; a published score changes only through the recorded rescoring pass, applied by a script, never by hand. How reports are handled.

Formal blind replication

A blind replication gives the scorer the protocol, the criteria and the corpus without the target system's scoring, and compares the result criterion by criterion. The first, of Ostrom-style commons governance, is on the record. The contributing guide explains how to run one, and section 11 of the scoring protocol sets the rules.
